Каталог для хранения шрифтов.

Если файл /src/styles/default/fonts.scss не существует сборка автоматически
создает его и подключает в него все шрифты из данного каталога. Если файл уже 
существует, то после добавления новых шрифотов в каталог нужно удалить файл 
/src/styles/default/fonts.scss и перезапустить сборку. При желании можно добавить
новый шрифт в ручную.
